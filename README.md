Este proyecto implementa una calculadora básica desarrollada bajo principios de **Ingeniería de Software** y evaluada mediante prácticas de **Aseguramiento de la Calidad (QA)**.

Incluye:

- Pruebas unitarias con Jest
- Integración continua con GitHub Actions
- Reporte de calidad
- Automatización del flujo de pruebas
